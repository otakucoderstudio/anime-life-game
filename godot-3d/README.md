# شارع الحياة (Street of Life) - Godot 3D source

Godot 4.3, GL Compatibility renderer, Android export (arm64).
Open this folder in Godot 4.3. Main script: main.gd.
Characters are modeled in Blender 4.2 by blender/chars.py:
  blender -b --python blender/chars.py -- girl_long   (also girl_bob boy_spiky boy_soft cat)
and exported to chars/*.glb (vertex-color regions, recolored by char.gdshader).

Assets and licenses:
- 3D props: Kenney Furniture Kit, Mini Market, Food Kit (CC0), models/
- UI sounds: Kenney Interface Sounds (CC0)
- Music, footsteps, ambience, characters: made for this project
- Painted art in art/ is the owner's own designs
