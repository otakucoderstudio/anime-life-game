# شارع الحياة (Street of Life) - Godot 3D source

Godot 4.3, GL Compatibility renderer, Android export (arm64).
Open this folder in Godot 4.3. Main script: main.gd.

Assets and licenses:
- 3D props: Kenney Furniture Kit, Mini Market, Food Kit (CC0), models/
- UI sounds: Kenney Interface Sounds (CC0), audio/bong, click, open
- Music, footsteps and ambience in audio/ are synthesized for this project
- Painted art in art/ is the owner's own designs
